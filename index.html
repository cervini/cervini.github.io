REInventory

Latest project

A shared inventory manager for tabletop RPG campaigns. Players organize items on a visual grid while campaign inventory changes sync in real time with the party and Dungeon Master.

React 19 · Firebase · Firestore · @dnd-kit

  • Drag-and-drop inventory grid
  • Shared, real-time campaigns
  • Item compendium and installable PWA

Backend choice. I used Firestore for sync because it already provided real-time updates and was free at my initial user count. A tabletop session doesn't need the ultra-low latency that WebSockets would offer, so a custom server wasn't worth the extra work.

Conflicts. If two players place the same item, the first one keeps it. The app supports games between friends with their own house rules and a DM who decides, so heavier conflict resolution would add complexity nobody needs.

Hardest part. Making drag and drop on the grid feel satisfying to use.
